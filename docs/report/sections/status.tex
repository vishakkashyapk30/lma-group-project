\section{Project Status}
\label{sec:status}

\paragraph{Built.} The six agents and the event log; the ten stores; the ingestion ladder; contracts and Sutradhar; Vakeel's check and repair; Abhiyojak; truth maintenance with the byte-identity test; Pairokar; the Rights Radar (seven of seven rules matched against the statute store by script); both gates and the privacy boundary; the web interface in English and Hindi, and the API routes. Six recorded synthetic demo cases load when the API starts, and each has a nine-step guided tour (Section~\ref{sec:system}). For evaluation: test sets T1 to T9, gold G1 to G7 (Table~\ref{tab:kappa}), baselines B0 to B6, every S/A/P variant as a switch (61 of 61 pass an offline end-to-end audit; 42 effect tests), the scoring pipeline (bootstrap, Wilcoxon, McNemar, cluster bootstrap, Holm), the label-source sweep, the offline studies, the code stamp in every manifest, and spend ledgers for both hosted providers. On 29 October the test suite (run per area; the fine-tuning folder excluded) gave 5,082 passed and 0 failed: 4,665 unit, 133 integration and 284 system tests; 5,264 tests are collected after the changes of that day.

\paragraph{Since the first draft of this report.} The team locked the paid providers in code and moved hosted calls to the Gemini free tier (providers are added by configuration); added per-case consent and quasi-identifier aliasing to the privacy boundary; bound Gate 2 to a hash of the approved brief; bound each Rights rule's verification to a hash of its text and code; made the unsupported-fact metric use MiniCheck and refuse the system's own checker; built BGE-M3 side vectors for the four vector stores; ran the architecture search and the sealed blind slice (Sections~\ref{sec:arch} and~\ref{sec:blind}); and, after the freeze, repaired the statute-store bail flags (13 November), the section extraction and the maximum-punishment lookup of the Rights Radar (15 November), added the opt-in sparring reserve that the product runs at 200,000 tokens, translated the interface into Hindi, and recorded the six demo cases. Two repairs of committed result files are recorded as deviations D13 and D14 of the pre-registration (Section~\ref{sec:limitations}).

\paragraph{Where the project stands.} The six agents, ten stores, two approval gates, the Rights Radar, the pseudonymisation boundary, 46 opt-in switches for literature variants, an evaluation pipeline with its statistics, the Hindi interface and the six demo tours are implemented and tested (about 5,000 tests). Baselines, ablations and variants ran on hosted models, the architecture search chose c1457 on development orders, and c1457 was tested once on 80 sealed orders with five registered hypotheses (Section~\ref{sec:blind}).

\paragraph{Code.} All code, tests, documents, the report source, run manifests and the tags \texttt{dev-sweep-v3}, \texttt{prereg-v1} and \texttt{eval-freeze-v1} are in the repository \url{https://github.com/vishakkashyapk30/lma-group-project}. Data, model weights and keys are not in it; \texttt{make setup}, \texttt{make data} and \texttt{make models} rebuild them (Appendix, Reproducibility).
