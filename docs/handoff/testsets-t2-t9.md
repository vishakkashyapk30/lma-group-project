## T2 (done; HLDC and e-SCR not available)
Files: `testsets/{t2_messy_bundles,rendering,degrade,companions}.py`, `scripts/build_testsets.sh`, `pyproject.toml` (extra `testsets`), `NOTICE` (PyMuPDF AGPL, Noto fonts OFL).
Design: each of 100 T1 cases (open part, Latin script first) becomes 6 bundles, one per kind K1 to K6: 600 bundles, 2,300 pages (about 3.8 pages each). A bundle is the court order (T1 facts text; a templated Hindi order summary for K5 and K6) plus a FIR on the IIF-1 layout and a remand order always and a custody certificate in 68% of bundles (3 or 4 documents), in a seeded order. Truth row: bundle id, case id, kind, `text_layer` (exact / none / legacy_gibberish), exact page text, document boundaries and types, field values (G3 values copied when T1 has them: arrest date for 20 of 100 cases, sections for 82, custody days for 41; the rest constructed with a seed and listed in `constructed`).
Checked on the real build: the text layer of all 100 K1 and all 100 K5 bundles equals the truth pages (whitespace-insensitive); K2 to K4 have no text; K6 has ASCII gibberish and no Devanagari.
Rendering: PyMuPDF (installed into `.venv` by copying the wheel contents from the uv cache because the network was too slow; `pip install .[testsets]` is the supported route), Pillow and NumPy for the raster kinds. Hindi from the machine's Noto Serif Devanagari (OFL); Latin letters inside Hindi lines are drawn with Times because the Devanagari font has no Latin letters. Page wrapping uses measured widths so no line is clipped.
Degradation is Pillow/NumPy (blur, grain, skew, fading, specks, fax streaks, stamp, signature stroke, JPEG), deterministic per seed. Augraphy is not used (it pulls OpenCV); `engine="augraphy"` is wired but untested. The two existing degrade tests asked for Augraphy and now ask for Pillow (`# RECONCILED`).
Approximations to know: K6 is a raster page plus an invisible Kruti-Dev-style ASCII text layer, not vector glyphs of a real legacy font (the mapping is ours, not the exact Kruti Dev table). The Hindi order of K5/K6 is a templated summary from the case values, not a translation of the T1 text (no translation model or Sarvam call is used). The plan's 4,800 pages need the 200 HLDC documents, which need Hugging Face access nobody here has: with them the count rises (each HLDC document is a one-document K5 bundle, up to 200; e-SCR up to 100, both `--hldc` and `--escr` directories of `*.jsonl` rows {doc_id, text}).
`scripted_counsel(truth)` is done (matches keys by words, flattens nested values, gives dd.mm.yyyy, returns `clean_copy` when asked for a clearer copy, a non-answer otherwise).
Commands: `.venv/bin/python -W ignore -m vakeel_sahayak.testsets.t2_messy_bundles [--small|--cases N]` (full: about 3 minutes; `--small`: 12 cases). The T2 tests take about 100 seconds because they render PDFs.

## T2 native Hindi fallback (2026-10-26, opt-in)
HLDC is still gated, so `testsets/t2_messy_bundles.py` got an opt-in source: `build_t2_with(..., native_path=...)` / CLI `--hindi-native data/interim/hindi_native.jsonl` (+ `--native-only` to build just those into `data/testsets/t2_hindi_native/`). It draws 200 documents by seed (`random.Random(f"{seed}|hindi_native")`), each one K5 bundle (`hnat-<case_id>`, one `COURT_JUDGMENT_HI` document, text cut at 5,000 characters on a space, exact text layer), truth row with `origin: "native_hc"` and a `source` block (case id, court, year, decision date, characters cut); manifest `details.hindi_native`. No other row changes: without the option the truth file and manifest are byte-identical (test `test_default_t2_output_is_unchanged_without_native`). The interim file comes from `pipelines/hindi_native.py` (see `data/README.md`): 6,889 orders kept of 7,554 candidates (364 below 50% Devanagari, 292 under 800 characters, 8 Supreme Court, 1 duplicate, 0 leakage). Real build: 200 bundles, 452 pages, 28 MB, 116 s; all Allahabad High Court (2020: 4, 2021: 1, 2023: 103, 2024: 3, 2025: 89). Not changed: `data/testsets/t1` to `t9` (the new folder is separate; T6 does not use it). Tests: `tests/unit/testsets/test_t2_hindi_native.py` (7, small parquet and JSONL fixtures). Caveat: High Court Hindi, not UP district-court Hindi; report `native_hc` apart from `translated` and HLDC; there are no field values for these bundles, only text, boundaries and type.
