## Restore, in order

About 10 GB of downloads for the data and 6 to 23 GB for models; allow an hour or more.

```bash
git clone https://github.com/vishakkashyapk30/lma-group-project.git && cd lma-group-project
# put your saved .env in the repository root (it holds HF_TOKEN)
make setup                      # .venv, dependencies, git hooks
make data                       # base bundle from vakeel-sahayak-data (includes data/raw)

# the 21 Nov snapshot on top (newer interim/stores/testsets, all eval runs, Sarvam cache, BGE vectors)
set -a; . ./.env; set +a
.venv/bin/hf download Vakeel-Sahayak/vakeel-sahayak-snapshot-2026-11-21 --repo-type dataset --local-dir data

make data-check                 # table of present / missing items
make models                     # T1 helper models (BGE-M3, DeBERTa NLI, MiniCheck, Whisper small), about 5.5 GB
VS_MODELS=T2 make models        # only if needed: Qwen3-4B and Qwen3-VL-4B-Instruct, about 17 GB

cd frontend && npm ci && npm run build && cd ..
make test-collect && make smoke # quick checks that the copy works
```

The snapshot is a plain mirror of `data/` (the same paths), so `--local-dir data` puts every file back where it was. Its SQLite files were copied with no process writing to them; their `-wal` and `-shm` side files were uploaded too, so open each database with its side files present.
