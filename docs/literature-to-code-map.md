# Literature to code map

Which idea in the code came from which paper, which switch turns it on, and where it is tested. Variant ids (S1-S17) and ablation ids
(A11b, A16, ...) are those of `docs/evaluation-plan.md` section 3.3; the literature review (`docs/literature-review-and-usage.md`)
uses its own ids (R1, R2, S2, ...) which are named in the idea column. None of these is a reproduction of the paper: each row says
what is adapted. Every switch defaults to the current behaviour.
